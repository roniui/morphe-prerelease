# ⚠️ Morphe apk builder with pre-release(dev) patches

<big>Features</big></summary>
<ul>
 <li>Supports pre-release patches and custom link patches. If patches are not released and from direct artifact then download that artifact file, upload it any cloud storage/github repo, use that file link in build workflow.</li>
 <li> Supports all present and future Morphe apps (including projects implementing the same API)</li>
</ul>

To use Latest stable releases [click here](https://github.com/roniui/morphe)
